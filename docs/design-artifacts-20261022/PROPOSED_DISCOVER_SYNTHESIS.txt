RESEARCH DRIVE — PROPOSED DISCOVER AND SYNTHESIS COMPOSITIONS
Proposed 2026-10-22. This is a PROPOSAL, not frozen authority. Nothing here has been
approved or built. Geometry: 24 nav | 77 centre | 37 Detail/Ask rail (same as FROZEN_RENDERS.txt).

WHAT CHANGES
  W1  Discover idle: one question, one box, one line of suggestions. No library block,
      no source list. (Supersedes the idle part of FROZEN_DISCOVER_EXPLORE_G, which was
      drawn with a question already asked. G's results composition is kept in spirit.)
  W2  Discover results: counts appear once as filter chips; one row open; the detail
      rail shows source, coverage, licence and unknowns, each "not reported" if absent.
  W3-W6  Synthesis: a diagram of datasets, steps and output (dbt-lineage layout), with the
      agent in the rail. Accepting the method and approving the run stay separate gates.

RULES CARRIED OVER from FROZEN_DISCOVER_EXPLORE_G: a badge states a holding and a route
states a measurement; coverage is never printed unless a field reports it; one row open;
actions scale with state; no number the backend does not emit.

BACKING (verify before building)
  EXISTS   join key columns, match rate and cardinality (joinCandidates.js, backend join
           candidates); dataset grain and column names; saved-method count (synthesis
           profiles); execution states Requested / Ran / Archived / Registered and row
           count; bounded output preview rows.
  UNVERIFIED  licence field on dataset records; a numeric column summary or chart for the
           output (a time sparkline was REMOVED from the first draft for this reason); the
           left-key count in "94% of the 6,240 left keys match" (denominator source).
  INTERACTION NOT YET DRAWN  keyboard traversal between diagram nodes, edit controls for a
           step, and what "Edit step" does to an accepted method (it must invalidate it).

LOOP LOG
  Round 1  drafted five frames.
  Round 2  fixed edge alignment; removed text repeated between centre and rail; split
           "Approve & run" because accepting a method and approving a run are separate gates.
  Round 3  independent review (Codex) added: a step-selected state, "Accept method",
           one conversation entry in the new build, "Search" instead of "Explore",
           licence/source rows marked not reported, no unverified chart.
           Rejected from that review: replacing "READY TO QUERY" (it is the project's
           holding word) and removing the saved-method count (the backend returns it).
